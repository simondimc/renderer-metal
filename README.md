# renderer-metal

## Cmake

```
rm -rf build
mkdir build && cd build
cmake ..
cmake --build .
./Renderer
```

## Goals

### Basics
- Triangle
- Cube
- Textures
- Lighting
- Interactive Camera

### Engine
- Frame-Resource Synchronization
- Loading Assets
- Offscreen Rendering & Post-Processing

### Realism
- Physically Based Rendering (PBR)
- Heightmap-Based Terrain & Tessellation
- Instanced Rendering

### Optimization
- Spatial Partitioning
- Frustum Culling

### Advanced
- Shadow Mapping
- Volumetric Atmosphere & Sky
- Water
- Physics Engine
- Ray Tracing
- Path Tracing
